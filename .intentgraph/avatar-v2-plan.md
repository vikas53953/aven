## Required identities

Cloud, Router, Switch, Firewall, Load Balancer, Wi-Fi, DNS / DDI, SD-WAN, Leaf, Spine, Server, Storage, VPN, Proxy, Monitoring, Controller.

## Shared output contract

1. One SVG asset per role, with an honest source/provenance record.
2. A typed React NetworkAvatar and named component per role, using the same artwork source as the browser renderer and SVG exports.
3. Shared role, size, color, geometry and motion tokens/constants.
4. Nine states: idle, hover, selected, listening, thinking, speaking, success, warning, offline.
5. A CSS animation system with reduced-motion fallback and explicit activity ownership.
6. A preview gallery: all 16 roles, nine states, and 20/24/32/48/64/96px checks.
7. Clear source/export/component/documentation structure.

## Visual and interaction constraints

Dark premium interface, warm amber/orange base, consistent face/feet/stroke/spacing family, crisp small-size silhouettes. Preserve supplied idle artwork. Add restrained state and interaction layers without replacing the baseline. Keep gallery tiles mostly still. Only selected/focused avatar may animate conspicuously. Uploaded photos keep their pixels and receive no facial or body distortion. Respect reduced motion. Colors are not the only state cue; pair status meaning with text. Do not announce repetitive animation frames to assistive technology.

Contexts: sidebar, coworker picker, detail pane, chat header, empty/onboarding/status examples. Preserve P4 automatic saving, upload, sections, composer, settings and conversation identity. The local prototype does not acquire a live agent lifecycle merely by rendering states.
