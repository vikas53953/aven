# Completion work

The original 115 feature requirements and previous verdicts are frozen in baseline-ledger.json. Original requirements own feature meaning; the last independent audit owns the prior status. Neither is overwritten by an agent's implementation claim.

## Owner and order

1. Reliability: drafts, queues, cancellation, recovery, independent runs and duplicate prevention.
2. Provider: explicit provider/model/effort selection, capability validation and response provenance.
3. Workflows: pending questions, scope-bound approvals and receipts. Runtime integration follows the provider contract.
4. Minimal interface: collapsed artifact bodies, optional evidence/investigation/run details off by default, Agent/Plan in the plus menu, context ring beside Send. Required decisions and failures remain visible.
5. Workspace: attachments, device identity, generated artifacts, topology, procedures and capability/session boundaries.
6. History: remaining navigation, history integrity, settings and existing-feature acceptance checks.
7. Ledger: all original requirements retain an owner, evidence, status and limitations; new UI requests are separately recorded.

## Integration contract

Workers edit candidate copies only. Each change supplies source hashes, touched paths, exact replacement hunks and focused results. Root checks overlap and integrates sequentially. Shared runtime changes must preserve isolated state before concurrent execution is enabled. Rendering and proposal creation never dispatch actions. No actual provider/device calls, credential retrieval or user-history mutation is part of the test run.

Acceptance covers reload/restart, FIFO order, idempotency, concurrent claims, stale tokens, unsupported provider selections, cancellation, unavailable states, keyboard access and responsive rendering. Zero external calls are asserted in mock tests. Final verification includes syntax/start smoke checks, relevant backend regression, live visual inspection and independent review of boundaries and status claims. Architecture documentation and the Excel register are updated after evidence is available.

Advisor approved the revised plan with these gates. Missing external contracts remain explicit; a mock-only test is never represented as live acceptance.
