# Round2 workspace gap and bounded change

The frozen workspace candidate already covers UX023 and UX026 through
`workspace-capabilities.js` and its injected unit/browser fixtures. UX082 had
only an exported renderer and synthetic-container test: the assembled shell's
Network sandbox pane never mounted it. This round2 replacement mounts a
topology evidence section in that pane. It derives nodes only from returned
inventory records and accepts links only from an explicit `sandboxResult.topology`
payload, so the UI cannot invent links. The renderer keeps source, freshness,
stable node IDs and observed/inferred link labels visible; records without an
actual ID remain unavailable/nonselectable instead of receiving a generated
target identity.

The base input is the frozen `completion/assembled-candidate/polished.js` and
the copied capability files are the frozen workspace candidate. The replacement
carries the UTF-8 seam hashes and full frozen-input hash; validation applies it
only in memory.
