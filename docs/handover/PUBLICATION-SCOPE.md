# Publication scope

Included: current application/backend source, package lockfile, application avatar
artwork, architecture/specification records, central workbooks, and historical
candidate source plus screened textual evidence. Candidates retain their original
paths and are not represented as integrated or accepted.

Excluded categories (originals preserved locally):

- Dependencies, virtual environments, browser profiles, caches and runtime state.
- Environment files, credential stores/key files, local databases, process files
  and logs.
- Runtime conversation/device run records and historical evidence containing
  private network addresses.
- Unreviewed screenshots, reference captures and other media except app avatar
  artwork. Some historical links therefore point to local-only evidence.
- Unrelated personal documents and sibling projects from the workspace.
- Firstmate credentials, authentication codes, private state and installed binaries.

Historical scripts/documents may contain machine-specific paths and assumptions.
Treat them as provenance, not as portable commands to execute blindly. The active
application launchers use their project directory. Never import personal local
profiles or secrets just to reproduce the published tests.

This snapshot intentionally changes no application behavior. Before continuing
development, select one Git checkout as the authoritative working copy and reconcile
newer changes in the original local folder. Do not synchronize in both directions.
